
# 🎬 Netflix Clone

> 🍿 A Netflix-inspired movie streaming website built using HTML and CSS.

## ✨ Features

- 🔴 Netflix-inspired navigation bar
- 🎥 Cinematic hero section with background image
- 🌐 Language selector and Sign In button UI
- 📧 Email sign-up interface
- 🍿 Recommended movie section
- 🔥 Top 6 movie suggestions
- ❓ Expandable Frequently Asked Questions (FAQ)
- 📩 Contact Us form
- 🖤 Attractive black-and-red theme
- ✨ Hover effects on movie cards
- 📱 CSS media query for smaller screens

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **Flexbox** — Element alignment
- **Media Queries** — Responsive styling

## 📂 Project Structure

```text
Netflix-Clone/
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enjoy exploring the website!
